# TJUFZ personal account page

A Chinese-language personal account page, with a clear disclaimer that the statements are unverified personal experiences and opinions.

## Publish with GitHub Pages

1. Open **Settings → Pages** for this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then save.
4. Wait for the Pages deployment to finish. The site should be available at `https://keilymarfriel-png.github.io/TJUFZ/`.

`index.html` is the homepage. `robots.txt` allows search crawlers and points to `sitemap.xml`. Search engines may take time to crawl and index a newly published site; publication does not guarantee inclusion or ranking. After Pages is live, verify the sitemap and optionally submit it in Google Search Console or Bing Webmaster Tools.
